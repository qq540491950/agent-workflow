# 12: 执行列表摘要与游标分页

**Blocked by:** 03 工作区解析与租约拒绝, 05 失败分支 tracer bullet.

**Status:** ready-for-agent

- [x] 列表响应使用执行摘要：id、工作流信息、状态、任务、时间、错误、工作区目录、`via_failure_branch`；不包含 snapshot、state_json、节点明细
- [x] 列表默认 50 条，最大 500；`limit=0` 按默认值处理，不再表示“全部”
