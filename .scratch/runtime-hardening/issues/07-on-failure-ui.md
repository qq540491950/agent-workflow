# 07: 失败分支设计器与监控展示

**What to build:** 设计器里可以把一条连线标记为失败边，并在画布上看出区别；保存、重新打开后标记不丢。监控页能看出这次执行是“经失败分支完成”，并能在校验失败时定位到具体连线或节点。

- [x] 校验错误能定位到失败边或相关节点，中文提示可读
- [x] 执行列表/详情显示“经失败分支完成”徽标，失败节点仍显示 FAILED
