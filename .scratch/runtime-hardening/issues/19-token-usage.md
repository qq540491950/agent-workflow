# 19: Token 用量采集与展示

**What to build:** 当 Agent CLI 的输出里带有 token 用量时，节点详情、执行详情和导出记录能看到输入/输出/总 token；没有用量信息时保持空值，不猜测、不内置价格表。用户可以用它判断一次执行的成本来源和哪个节点最耗 token。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] Agent 响应新增可选用量字段：输入 token、输出 token、总计、模型、可选成本
- [x] Claude 适配器在输出信封含 usage 时解析；不含或形态不认识时留空，不猜测
- [x] 节点明细与执行记录持久化用量；执行级聚合总计；旧库迁移幂等
- [x] 执行详情、导出记录与前端展示用量；没有数据时显示“—”而不是 0
- [x] 不硬编码模型价格；成本只在 CLI/适配器明确提供时展示
- [x] 用量数据不包含 prompt 全文或凭据；脱敏出口不变
- [x] 测试覆盖有/无 usage、异常形态、执行聚合、导出与前端展示
