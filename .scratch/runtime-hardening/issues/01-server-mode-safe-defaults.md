# 01: 服务模式安全默认与远程令牌

**What to build:** 用户以服务器模式启动时，默认只能从本机访问；要暴露到非回环地址必须显式开启远程模式并提供令牌。无令牌的远程请求被拒绝，启动令牌只出现一次，HTTP 服务器具备最基本的读头/空闲超时；桌面模式完全不受影响。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 默认 `--server` 只监听回环地址；`--addr :8080`、`0.0.0.0:8080` 或局域网地址在未开启远程模式时启动失败，并给出可读原因
- [x] 新增显式远程开关与 `--auth-token`；未提供 token 时启动生成一次性随机 token，仅打印一次，不进入日志、SQLite 或 API 响应
- [x] 远程模式下除健康检查外的 `/api/*` 均要求 `Authorization: Bearer <token>`；缺失或错误返回 401 `UNAUTHORIZED`，响应体符合统一错误形状
- [x] 健康检查在远程模式可无 token 访问，且不泄漏路径、凭据或内部错误
- [x] HTTP 服务器配置读头超时、读超时与空闲超时；SSE 不被全局写超时掐断
- [x] README、API 文档与冒烟脚本同步；回环冒烟无需 token，远程负路径有 401 用例
- [x] 桌面模式与既有服务器回环行为回归通过
