# 13: 事件游标与监控增量

**What to build:** 监控页不再每收到一个事件就重拉整段事件历史。首屏取最近一页，实时事件直接追加，超过上限提示并允许加载更早；完整审计仍可通过导出查看。事件 API 支持按 seq 游标读取，长执行不会越跑越卡。

**Blocked by:** 12 执行列表摘要与游标分页.

**Status:** ready-for-agent

- [x] 事件接口无参数时返回最近 N 条（默认 500、最大 2000），按时间升序
- [x] 支持 `after_seq` 增量与 `before_seq` 加载更早；两者互斥，同时出现返回 400
- [x] 响应头返回本次最大 seq；事件顺序稳定，`seq` 不重复
- [x] 监控页首屏取最近一页；SSE 到达时直接追加并去重，不再全量重拉
- [x] 内存事件上限 2000；超出丢弃最旧并提示“仅显示最近记录，完整记录请导出”
- [x] 支持“加载更早”；执行/节点/制品刷新与事件刷新解耦
- [x] API 与前端测试覆盖 tail、after、before、互斥参数、追加去重与上限；事件脱敏不变
