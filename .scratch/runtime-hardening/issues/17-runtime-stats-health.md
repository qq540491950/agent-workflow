# 17: 运行时统计与健康检查

**What to build:** 用户和运维能看到系统现在到底在做什么：运行中、排队中、队列深度、最老等待时间、成功/失败/取消计数、事件落库失败、状态提交失败、SSE 订阅数与数据库延迟。健康检查不再永远返回 ok，数据库不可用时会明确失败。

**Blocked by:** 09 QUEUED 状态与调度器, 10 队列恢复、满载与公平性.

**Status:** ready-for-agent

- [x] 新增只读运行时统计端点，返回运行中、排队中、队列深度、最老等待时长、完成/失败/取消计数
- [x] 返回事件落库失败、状态提交失败、Escalate 预期/异常计数与 SSE 订阅数
- [x] 返回数据库 ping 延迟（可选 p50/p95 窗口）；统计值在并发执行下保持一致
- [x] 统计响应稳定、无敏感信息；服务器模式下按既有鉴权规则保护
- [x] 健康检查执行数据库 ping；数据库不可用返回 503，且不泄漏路径/SQL/凭据
- [x] 设置页或总览页展示关键统计，刷新走防抖，不因轮询造成额外压力
- [x] 后端与前端测试覆盖统计字段、并发计数、健康 200/503；`-race` 通过
