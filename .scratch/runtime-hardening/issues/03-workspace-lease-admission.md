# 03: 工作区解析与租约拒绝

**What to build:** 每次执行在启动时解析自己会用到的工作目录，并对这些目录取得独占租约。两个执行同时使用同一工作目录时，后一个得到明确的 `WORKSPACE_BUSY`，不会在用户不知情时互相改文件；执行记录和界面能看到这次执行用了哪些目录。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 从执行快照的全局 Git 目录与 agent/script/git 节点 `working_dir` 解析目录；规范化为绝对路径、去重、排序
- [x] 执行启动前获取所有目录的租约；多个目录按字典序获取，部分失败时释放已获取的目录，不留下半持有状态
- [x] 同一目录已有活跃执行时，新的启动返回 409 `WORKSPACE_BUSY`，且不创建执行记录
- [x] 不同目录的执行仍可并发，不被误伤
- [x] 执行记录持久化工作区目录列表，执行详情/API/UI 可查看
- [x] 执行完成、失败或取消时释放租约；释放幂等
- [x] 集成测试使用临时 Git 目录覆盖同目录拒绝、不同目录并发与释放；`-race` 通过
