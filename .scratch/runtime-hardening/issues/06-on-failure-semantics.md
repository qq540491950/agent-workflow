# 06: 失败分支深度语义

**What to build:** 把失败分支从“能跑”变成“可恢复、可校验、不会掩盖错误”：重试先于失败分支；失败分支中的等待人工可以恢复且路由不换道；失败分支自身失败时执行最终 FAILED 并同时保留两段原因；并行区、错误条件和非法环在校验期就被拒绝。

**Blocked by:** 05 失败分支 tracer bullet.

**Status:** ready-for-agent

- [x] 重试期间不触发失败分支；最后一次失败后才触发，`node.retry` 事件序列不变
- [x] 失败分支中的 human 节点等待后可以 Resume；失败路由以结构化状态回放，不重新求值条件
- [x] 失败分支自身失败时执行落 FAILED，错误信息同时包含原始失败与分支失败原因
- [x] 校验期拒绝多条失败边、自环、带条件的失败边、并行区内的失败边与无条件失败环，并返回对应错误码
- [x] 收尾可达性判定区分“普通可达”与“仅失败可达”，失败分支未执行时不被误报为不可达
- [x] 并行区内的失败边明确拒绝（V1 只支持顺序上下文）
- [x] 所有负路径有“改坏实现就变红”的回归测试；`-race` 通过
