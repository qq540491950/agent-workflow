# 04: 工作区租约生命周期

**What to build:** 工作区租约跟随执行的真实生命周期：等待人工审批时释放，避免一个挂起的审批长期占住目录；用户提交审批或重试时重新获取；如果此时目录已被别的执行占用，明确返回 `WORKSPACE_BUSY`，不继续执行。

**Blocked by:** 03 工作区解析与租约拒绝.

**Status:** ready-for-agent

- [x] 执行进入 `WAITING_USER` 时释放租约，其他执行可以使用同一目录
- [x] `Resume` 与 `RetryNode` 在启动执行协程前重新获取租约
- [x] 重新获取失败时返回 409 `WORKSPACE_BUSY`，执行状态保持 `WAITING_USER` / `FAILED`，不产生副作用
- [x] 终态与取消路径释放租约；协程 defer 与显式释放不会重复破坏引用计数
- [x] 多目录租约在等待/恢复/结束路径上全部释放或全部重新获取
- [x] 并发等待、恢复、取消组合在 `-race` 下通过，无租约泄漏
- [x] 执行详情能反映当前工作区占用状态或最近一次租约结果
