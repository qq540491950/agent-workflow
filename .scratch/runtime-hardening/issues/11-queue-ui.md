# 11: 排队 UI

**What to build:** 用户在界面上能看出一个执行是在排队、排在第几位，并能取消排队；执行列表可以按 `QUEUED` 过滤，不再把排队误读成“还没开始”或“卡住了”。

**Blocked by:** 09 QUEUED 状态与调度器.

**Status:** ready-for-agent

- [x] 状态徽章与文案映射包含 `QUEUED`，未知状态仍回退原文
- [x] 执行列表/详情显示队列位置；非排队状态不显示位置
- [x] `QUEUED` 执行提供“取消排队”操作，成功/失败都有明确提示并刷新
- [x] 执行列表过滤包含排队状态；空态与“无匹配”文案区分
- [x] 实时事件到达时防抖刷新，不出现旧响应覆盖新列表
- [x] 前端测试覆盖徽标、位置、取消、过滤与空态；`npm run build` 与 vitest 通过
