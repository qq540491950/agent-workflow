# 10: 队列恢复、满载与公平性

**What to build:** 排队不是一次性内存行为：重启后已接受的排队请求仍在；队列满时明确拒绝；多个工作流同时排队时按公平策略轮转，不让一个大工作流长期饿死其他工作流。

**Blocked by:** 09 QUEUED 状态与调度器.

**Status:** ready-for-agent

- [x] 启动时把持久化的 `QUEUED` 执行按 `queued_at` 顺序重新入队
- [x] 工作流已删除、被禁用或快照损坏的排队执行落 `FAILED`，给出可读原因
- [x] 队列达到上限时返回 `QUEUE_FULL`，不创建超额执行记录
- [x] 公平策略按工作流轮转；FIFO 策略按入队顺序；两种策略均可配置
- [x] 优雅关闭不再取新执行，`QUEUED` 行保留供下次启动恢复
- [x] 队列深度、最老等待时长、拒绝次数可观测
- [x] 重启恢复、满载、公平性测试通过；`-race` 通过
